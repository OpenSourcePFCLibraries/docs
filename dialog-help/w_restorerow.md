# Restore Row dialog box

Use this dialog box to restore deleted rows. Rows that have already been saved to the database can't be restored. Select the rows to restore and click **OK**.

*Opened by `w_restorerow`.*

## Options

- **Select All**: Selects all the rows.
- **Invert Selection**: Reverses the selection: selected rows become unselected, and unselected rows become selected.

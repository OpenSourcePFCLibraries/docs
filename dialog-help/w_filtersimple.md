# Simple Filter dialog box

Use this dialog box to specify a filter, which controls the rows that are displayed.

*Opened by `w_filtersimple`.*

## Options

- **Original filter criteria**: Displays the original filter expression.
- **New filter criteria**: Select items from the Column, Operator, Value, and (optionally) Logical drop-down lists to specify the new filter criteria.

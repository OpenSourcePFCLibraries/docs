# Replace dialog box

Use this dialog box to find and replace text.

*Opened by `w_replace`.*

## Options

- **Find where**: The column in which to find the text.
- **Find what**: The text to find.
- **Replace with**: The replacement text.
- **Search**: Searches up or down.
- **Whole word**: Whether the text must match a whole word.
- **Match case**: Whether uppercase and lowercase must match.
- **Find Next**: Goes to the next occurrence of the text.
- **Replace**: Replaces the current text with the replacement text.
- **Replace All**: Replaces every occurrence of the text with the replacement text.

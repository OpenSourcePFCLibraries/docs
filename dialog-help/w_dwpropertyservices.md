# DataWindow services

This dialog box is different for each DataWindow service. Use it to view and modify how the service is set up, and to view its syntax.

The Syntax tab shows the PowerScript that enables the service with its current options, including the ones chosen in the DataWindow Properties dialog box. You can copy this code and paste it into your scripts, or click **Save** to save it to a file.

*Opened by the service dialog boxes opened from w_dwproperty.*

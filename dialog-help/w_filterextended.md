# Extended Filter dialog box

Use this dialog box to specify a filter, which controls the rows that are displayed.

*Opened by `w_filterextended`.*

## Options

- **Filter expression**: Type a filter expression, or use the tabs to click items that help you define one. Click **Verify** to check the syntax.
- **Functions**: Click the list on the left to choose the group of functions displayed on the right. Double-click a function to add it to the filter expression.
- **Columns**: Double-click a column to add it to the filter expression.
- **Operators**: Double-click an operator to add it to the filter expression.
- **Values**: Displays the values of the selected column. Double-click a value to add it to the filter expression.

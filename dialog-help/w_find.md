# Find dialog box

Use this dialog box to find text.

*Opened by `w_find`.*

## Options

- **Find where**: The column in which to find the text.
- **Find what**: The text to find.
- **Search**: Searches up or down.
- **Whole word**: Whether the text must match a whole word.
- **Match case**: Whether uppercase and lowercase must match.
- **Find Next**: Goes to the next occurrence of the text.

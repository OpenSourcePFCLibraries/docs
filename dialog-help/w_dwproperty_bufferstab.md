# DataWindow Properties, Buffers tab

Use this tab to view and modify the DataWindow buffers.

*Opened by `w_dwproperty`.*

## Options

- **Buffer**: The row count and modified count of the Primary, Filtered, and Deleted buffers. The modified count applies to the Primary buffer only.
- **DataWindow display**: The contents of the selected buffer. Click the option buttons to change buffers.

# Default Filter dialog box

Use this dialog box to specify a filter, which controls the rows that are displayed. You can type a filter expression in the entry field, or click buttons, functions, and columns to build one.

*Opened by the DataWindow's own Specify Filter dialog box.*

## Options

- **Operator buttons**: Click a button to add the operator to the filter expression.
- **Functions**: Click a function to add its syntax to the filter expression.
- **Columns**: Click a column to add it to the filter expression.

## Example

This filter accepts only the rows in which qty_ordered is greater than or equal to 24 and qty_used is greater than 6:

```
qty_ordered >= 24 and qty_used > 6
```

# SQL Spy

Displays the SQL that has been executed and, optionally, each SQL statement before it updates the database, so you can review and change it.

*Opened by `w_sqlspy`.*

## Options

- **Inspect each SQL statement**: Whether PFC shows each SQL statement before it updates the database. If this check box is selected, SQL Spy opens the [SQL Spy Inspect](w_sqlspyinspect.md) dialog box for each statement.
- **SQL history**: The SQL statements that have been executed.
- **Clear**: Clears the contents.
- **Save**: Saves the contents to a file.
- **Print**: Prints the contents.

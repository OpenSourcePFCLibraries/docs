# DataWindow Properties, Services tab

Use this tab to view, enable, and disable DataWindow services.

*Opened by `w_dwproperty`.*

## Options

- **Service list**: All the DataWindow services. Select a service's check box to create it, and clear it to destroy the service.
- **Enable, Disable**: Enables or disables the service.
- **Property**: Displays a dialog box with the properties of the selected service (see [DataWindow services](w_dwpropertyservices.md)).

# Toolbars dialog box

Use this dialog box to control how the toolbars are displayed.

*Opened by `w_toolbars`.*

## Options

- **Toolbars**: The available toolbars. Select or clear the check box next to a toolbar to show or hide it.
- **Position**: Where the toolbar is displayed in the frame: at the top, bottom, left, or right, or floating. You can move a floating toolbar within the window.
- **Large buttons**: Shows large or small toolbar buttons. Large buttons can also display text.
- **Show tooltips**: Whether a tip is displayed when the mouse pointer rests on a toolbar button.

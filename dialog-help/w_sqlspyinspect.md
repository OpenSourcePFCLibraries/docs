# SQL Spy Inspect

Lets you view, and optionally change, SQL statements before PowerBuilder submits them to the database.

*Opened by `w_sqlspyinspect`.*

## Options

- **Statement**: The SQL statement to be submitted.
- **Step**: Executes this SQL statement and displays the next one.
- **Resume**: Executes this SQL statement and all the ones after it.
- **Cancel**: Skips this SQL statement and displays the next one.
- **Cancel All**: Skips this SQL statement and all the ones after it.

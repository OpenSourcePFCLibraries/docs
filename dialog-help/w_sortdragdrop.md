# Sort dialog box (drag and drop)

Use this dialog box to specify the sort criteria.

*Opened by `w_sortdragdrop`.*

## Options

- **Columns available for sorting**: The columns you can sort on. Drag a column from here to the Sort Columns list to sort on it.
- **Sort columns**: The columns the rows are sorted on. The column at the top is the primary sort criterion, and the ones below it are secondary criteria. Drag a column out of this list to stop sorting on it.
- **Ascending**: Sorts in ascending order if checked, and in descending order if not.

# Sort dialog box (multi-sort)

Use this dialog box to specify the sort criteria.

*Opened by `w_sortmulti`.*

## Options

- **Sort items by**: Select a column from this drop-down list to sort on it. The top entry is the primary sort criterion, and the ones below it are secondary criteria.
- **Ascending**: Sorts in ascending order if checked, and in descending order if not.
- **Insert, Add, Delete**: Inserts, adds, or deletes a level of sorting.

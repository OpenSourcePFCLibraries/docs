# Sort dialog box (default)

Use this dialog box to specify the sort criteria.

*Opened by the DataWindow's own Specify Sort Columns dialog box.*

## Options

- **Source data**: The columns the rows can be sorted on.
- **Columns**: The columns to sort on.
- **Ascending**: Sorts in ascending order if checked, and in descending order if not.

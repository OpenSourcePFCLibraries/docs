# About This Book

> PFC was originally developed by Sybase, Inc. and shipped with PowerBuilder. It is now maintained as an open source project by the [OpenSourcePFCLibraries](https://github.com/OpenSourcePFCLibraries) community. This documentation was converted from the original Sybase manuals, so some details (version numbers, file paths, screenshots, and tool names) reflect PowerBuilder 9 and may differ from current releases.

**Subject**

This book describes the objects in the PowerBuilder Foundation Class Library (PFC). Each object’s discussion includes:

- A diagram providing a quick overview of the object’s capabilities
- Instance variables
- Events and user events
- Object functions

**Online Help** The original PFC online Help file (pbpfc90.hlp) contains all the objects, events, and functions explained in this book. This Help file includes customized buttons and links to help you navigate through inheritance hierarchies and related objects.

For PFC usage information, see the *PowerBuilder Foundation Class Library User’s Guide*.

**Audience**

This book is for experienced PowerBuilder developers. It assumes that:

- You are currently developing applications using PowerBuilder and understand the concepts and techniques described in the PowerBuilder *Application Techniques* book
- You understand SQL and how to use your site-specific DBMS

**Two volumes**

The original printed version of this book was divided into two volumes: Volume 1 included Chapters 1-8 and Volume 2 included Chapter 9. This edition combines both volumes.

**Other sources of information**

- The PFC source code, issue tracker, and the latest version of this documentation are on GitHub at [github.com/OpenSourcePFCLibraries](https://github.com/OpenSourcePFCLibraries).
- Current PowerBuilder documentation is available from Appeon at [docs.appeon.com](https://docs.appeon.com).

**If you need help**

PFC is an open source project maintained by its community. To report a problem, ask a question, or suggest an improvement, open an issue in the relevant repository under [OpenSourcePFCLibraries](https://github.com/OpenSourcePFCLibraries). Contributions to the code and to this documentation are welcome as pull requests.

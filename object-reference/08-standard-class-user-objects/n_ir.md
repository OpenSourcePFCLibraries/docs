# n_ir

> Removed in PFC 2025. Available in the 2019 and 2022 versions of PFC. PowerBuilder's InternetResult object only receives the data that the Inet object's GetURL and PostURL functions return, so it was removed with [n_inet](n_inet.md). Use the HTTPClient object ([n_httpclient](n_httpclient.md)) instead.

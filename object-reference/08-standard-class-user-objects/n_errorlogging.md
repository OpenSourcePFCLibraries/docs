# n_errorlogging

> Removed in PFC 2025. Available in the 2019 and 2022 versions of PFC. PowerBuilder's ErrorLogging object writes to the log of the EAServer or MTS container a component runs in, which a PowerBuilder 2025 application doesn't run in. pfc_n_errorlogging was always empty and never had an n_errorlogging extension object.

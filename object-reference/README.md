# PowerBuilder Foundation Class Library Object Reference

> PFC was originally developed by Sybase, Inc. and shipped with PowerBuilder. It is now maintained as an open source project by the [OpenSourcePFCLibraries](https://github.com/OpenSourcePFCLibraries) community. This documentation was converted from the original Sybase manuals, so some details (version numbers, file paths, screenshots, and tool names) reflect PowerBuilder 9 and may differ from current releases.

This reference describes the objects in PFC: each object's instance variables, events, and functions. For concepts and usage, see the [PFC User's Guide](../user-guide/README.md).

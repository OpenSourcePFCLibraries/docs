# f_RemoveDuplicate

> Not covered in the original (PowerBuilder 9) edition of this reference. This page was generated from the PFC source code comments.


| Argument | Description |
| --- | --- |
| *aa_array* | Any array, passed by reference. |

**Return value**

**Usage**

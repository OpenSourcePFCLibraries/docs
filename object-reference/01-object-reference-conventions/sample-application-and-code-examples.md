# Sample application and code examples

**Sample application**

The PEAT sample application shows you how to use PFC for a simple project estimation and tracking system. It includes examples of windows, DataWindows, tabs, TreeViews, ListViews, and custom class user objects.

PEAT is in the `demoapp` folder of the [2025-Solution](https://github.com/OpenSourcePFCLibraries/2025-Solution) repository (`peat demo app.pbproj`). See its [README](https://github.com/OpenSourcePFCLibraries/2025-Solution/blob/master/demoapp/README.md) for setting it up.

**Code examples**

The APPEXAMP code examples application shows you how to use selected PFC objects and services. It includes examples of application services, windows, window services, DataWindows, DataWindow services, tabs, TreeViews, ListViews, and custom class user objects.

The code examples are in the `examples` folder of the 2025-Solution repository (`pfc examples.pbproj`). See its [README](https://github.com/OpenSourcePFCLibraries/2025-Solution/blob/master/examples/README.md) for setting it up and for the list of examples. Each example's help topic is in [PFCEXAMP.pdf](https://github.com/OpenSourcePFCLibraries/Example-application-help-file/releases/latest/download/PFCEXAMP.pdf).

Both applications show their menus as a ribbon, use a UI theme, and use SVG images. See “Giving a PFC application a current look” in [Chapter 6 of the User's Guide](../../user-guide/06-using-pfc-windows-and-menus.md#giving-a-pfc-application-a-current-look).
